## Acceptance decision

The UI conversion is implemented, but **the migration is not accepted as complete**. RTO fails against the unchanged backend; Windows WebKit cookie inspection remains unresolved; the specifically untested branches above and physical-device/OS/provider checks remain acceptance gaps. Native Admin/Seller removal is **NO-GO**, irrespective of successful compilation or the number of passing scenarios. No native source has been removed.
